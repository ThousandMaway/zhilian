# 使用指南

> 版本：v1.0 | 日期：2026 年 7 月

## 一、快速开始

### 1.1 安装 App

1. 下载 APK 安装包
2. 华为手机：设置 → 安全 → 允许安装未知应用
3. 点击 APK 安装

### 1.2 注册账号

1. 打开 App → 点击「还没有账号？立即注册」
2. 输入邮箱 + 密码（至少 6 位）→ 注册
3. 直接登录

---

## 二、导入题库

### 2.1 文件导入（推荐）

1. 底部 Tab → **题库** → **导入题库**
2. 选择 JSON / CSV / DOCX 文件
3. 系统自动解析 → 预览题目 → 确认导入
4. 导入后自动以文件名创建标签

### 2.2 手动录题

1. 题库 → **手动录题**
2. 切换题型（单选/多选/判断/填空/简答）
3. 输入题干、选项、答案、解析
4. 保存

### 2.3 模板说明

**JSON 格式：**
```json
[
  {
    "stem": "题干内容",
    "type": "single_choice",
    "options": [{"id":"A","content":"选项A"},{"id":"B","content":"选项B"}],
    "answer": "A",
    "analysis": "解析（选填）",
    "difficulty": 1
  }
]
```

题型取值：`single_choice` / `multi_choice` / `true_false` / `fill_blank` / `short_answer`

---

## 三、答题练习

### 3.1 随机练习

1. 答题 Tab → **随机练习**
2. 选择题库来源（可多选）
3. 选择题目类型（可多选）
4. 设置题目数量
5. 点击「开始随机练习」

### 3.2 题库练习

1. 答题 Tab → **题库练习**
2. 选择一个题库
3. 从头到尾顺序作答

### 3.3 答题操作

- **单选题**：点击选项 → 立即显示对错
- **多选题**：勾选选项 → 点击「确认答案」
- **判断题**：点击对/错按钮
- **填空题**：输入答案 → 点击「确认答案」
- **简答题**：输入回答 → 点击「确认答案」
- **上一题/下一题**：底部按钮
- **退出**：右上角「✕ 退出」

### 3.4 答题结果

提交后显示：
- 正确率百分比 + 等级评价（优秀/良好/加油/继续努力）
- 正确数、错误数、用时、总题数统计
- 「再来一组」或「返回练习」

## 四、学习工具

### 4.1 错题本

- 答题错误自动收录
- 我的 Tab → 错题记录 → 查看/移除
- 答题 Tab → 错题重练 → 专攻错题

### 4.2 收藏

- 答题中点击「⭐ 收藏」按钮
- 我的 Tab → 我的收藏 → 查看/取消/练习

### 4.3 每日打卡

- 每天完成 ≥20 题自动打卡
- 首页查看今日进度条
- 我的 Tab → 打卡记录 → 查看日历热力图

### 4.4 学习统计

- 我的 Tab → 学习统计
- 总答题数、正确率、各题型进度条、薄弱知识点

---

## 五、数据管理

### 5.1 导出

我的 Tab → 设置 → 导出全部数据 → 生成 JSON 文件

### 5.2 标签管理

- 题库页面点击「创建空题库」新建标签
- 长按标签 → 重命名 / 删除
- 删除标签会同步删除标签内所有题目

---

## 六、常见问题

**Q: 导入后找不到题库？**
A: 题库页面会以文件名自动创建标签卡片，点击卡片进入题目列表。导入的题不会进入默认题库。

**Q: 手动录的题在哪？**
A: 录题时可选择「所属题库」。如果没选标签，会显示在「未分类」卡片。

**Q: 打卡没更新？**
A: 完成一次答题后切回首页即可刷新。
