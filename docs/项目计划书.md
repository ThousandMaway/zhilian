# 项目计划书

## 一、项目概述

**项目名称**：智练 —— 智能刷题练习平台

**所属行业**：在线教育 / 移动互联网

**核心产品**：「智练」是一款面向备考学习者的移动端智能刷题 App。用户可自主创建或导入题库，系统支持单选题、多选题、判断题、填空题、简答题共五种题型，提供自由练习与试卷模式两种答题方式，搭配每日打卡、错题自动收集、题目收藏、答题统计分析等学习辅助功能。

产品以「人人可建题库、处处可刷题」为理念，打破传统刷题 App 题库封闭的局限。用户可通过 JSON、CSV 文件批量导入题目，支持 **DOCX 智能解析**（自动识别题干、选项、答案、解析），让任何有练习需求的人都能快速搭建专属刷题工具。

**技术架构**：前端 Expo (React Native) + TypeScript 跨平台框架，一套代码覆盖 iOS/Android。采用 twrnc (Tailwind) 样式方案与 React Navigation 导航体系。后端 Supabase 云服务实现数据持久化、用户认证与实时同步，Row Level Security 实现用户数据完全隔离。EAS Build 云端打包生成独立 APK。

**项目现状**：MVP 版本开发完成。36 个 TypeScript 源文件，3000+ 模块，TypeScript 编译零错误，Metro 打包通过。Android APK 构建中。

## 二、市场分析

### 用户画像

| 用户群体 | 典型场景 | 核心需求 |
|----------|---------|---------|
| 大学生 | 期末复习、考研、考公 | 自建题库、碎片化刷题、错题回顾 |
| 职业资格考生 | 教资、法考、医考、注会 | 大量刷题、多题型支持、进度追踪 |
| 企业培训部门 | 新员工考核、安全培训 | 自建题库、批量导入、考试模式 |
| 自由学习者 | 读书笔记、知识点记忆 | 自定义问答、每日打卡、统计分析 |

### 竞争对手分析

| 竞品 | 优势 | 劣势 |
|------|------|------|
| 粉笔 | 公考题库全面 | 题库封闭，不可自建 |
| 猿题库 | K12 覆盖广 | 用户面窄 |
| 考试宝 | 功能类似 | 界面传统、题型单一 |
| Anki | 间隔记忆算法 | 中文不友好、仅卡片式问答 |

市场核心痛点：**多数产品题库由平台提供，用户无法灵活自建；支持自建的产品不支持多题型；云同步普遍需要付费。**

### 差异化优势

1. **全题型覆盖**：单选、多选、判断、填空、简答五种题型，远超同类自建题库工具
2. **DOCX 智能解析**：上传 Word 文档自动识别题目结构，过滤标题/章节标记
3. **文件批量导入**：JSON/CSV 一键导入，自动字段映射
4. **免费云同步**：Supabase 云端存储，跨设备同步，零门槛
5. **独立 APK**：支持华为等国产手机，不依赖应用商店

## 三、产品或服务

### 产品现状

MVP 版本已完成全部核心功能开发。TypeScript 编译零错误，Metro 打包 3013 模块通过。EAS 云端构建中，构建完成后可直接安装到 Android 手机。

### 核心功能

| 功能模块 | 说明 |
|---------|------|
| **用户认证** | 邮箱注册/登录，SecureStore 加密存储，会话自动恢复 |
| **题库管理** | 手动录题（5 种题型动态表单）、JSON/CSV/DOCX 导入、搜索筛选分页 |
| **答题系统** | 5 种题型交互、自由练习（即时解析）、试卷模式（统一打分）、答题计时器 |
| **每日打卡** | 完成 20 题自动打卡、日历热力图、连续天数统计 |
| **错题本** | 答题错误自动收录、错误次数记录、错题重练 |
| **题目收藏** | 答题中一键星标、独立收藏列表、收藏练习 |
| **学习统计** | 总答题数、正确率、各题型进度条、薄弱知识点排行 |
| **数据导出** | 一键导出全部数据（题库、错题、收藏、打卡）为 JSON |

### 产品亮点

- **DOCX 智能解析引擎**：上传 Word 试卷自动识别题目结构，支持编号、选项字母、答案标记、解析段落，过滤试卷标题和章节标记
- **题型自适应表单**：录题时切换题型，表单即时变化——单选显示选项+单选按钮，多选显示选项+多选勾选，判断显示对错开关，填空/简答显示文本输入
- **智能判分**：简答题关键词匹配算法，填空题精确比对，多选/填空/简答需确认后才判分，防止误触
- **题型自动排序**：随机练习时先单选后多选再判断，从简到难逐步递进
- **离线优先架构**：本地 SQLite 缓存全量数据，断网可用，网络恢复后无缝同步

## 四、商业模式

| 收入来源 | 说明 | 预估占比 |
|----------|------|---------|
| **免费增值** | 基础功能永久免费：手动录题、基础答题、JSON/CSV/DOCX 导入（50 题以内）、每日打卡、错题记录、收藏 | —— |
| **会员订阅** | 月/年订阅制，解锁：无限题库导入、高级统计分析、数据导出、优先体验新功能 | 60% |
| **题库市场** | 优质题库创作者可定价售卖，平台抽取 20% 技术服务费 | 25% |
| **企业定制** | 面向企业培训场景提供私有化部署、SSO 集成、定制题型开发，按年付费 | 15% |

**定价策略**：会员月费 ¥12 ~ ¥18，年费 ¥98 ~ ¥128。以亲民价格覆盖从轻度到重度用户的完整付费梯度。

**核心竞争力壁垒**：DOCX 智能解析的技术积累 + 用户自建题库形成的数据网络效应 + 全题型覆盖的产品完整性，三者构成可持续的差异化护城河。
