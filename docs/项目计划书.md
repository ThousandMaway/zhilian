## 一、项目概述

### 基本信息

| 项目 | 内容 |
|------|------|
| **项目名称** | 智练 — 智能刷题练习平台 |
| **所属行业** | 在线教育 / 移动互联网 |
| **产品形态** | 移动端 App（iOS + Android） |
| **技术架构** | Expo (React Native) + TypeScript + Supabase |
| **开源地址** | [github.com/ThousandMaway/zhilian](https://github.com/ThousandMaway/zhilian) |

### 核心产品

「智练」是一款面向备考学习者的跨平台智能刷题 App。产品以**「人人可建题库、处处可刷题」**为核心理念，打破传统刷题 App 题库封闭的局限，让任何有练习需求的人都能快速搭建专属刷题工具。

系统支持**单选题、多选题、判断题、填空题、简答题**共五种题型，提供自由练习与试卷模式两种答题方式，搭配每日打卡、错题自动收集、题目收藏、答题统计分析等学习辅助功能。用户可通过 JSON、CSV 文件批量导入题目，更支持 **DOCX 智能解析**（自动识别题干、选项、答案、解析），上传 Word 文档即可完成题库录入。

### 项目现状

MVP 版本开发完成并已开源。**41 个 TypeScript 源文件**（14 个逻辑模块 + 27 个界面组件），TypeScript 编译零错误，Metro 打包通过。经过系统化代码审查和 14 项 bug 修复，代码质量已达到可交付水平。独立的 Android APK 可直接安装到华为等国产手机，无需依赖应用商店。

## 二、市场分析

### 2.1 用户画像

| 用户群体 | 典型场景 | 核心需求 | 预估规模 |
|----------|---------|---------|---------|
| 大学生 | 期末复习、考研、考公、四六级 | 自建题库、碎片化刷题、错题回顾 | 4000 万+ |
| 职业资格考生 | 教资、法考、医考、注会、一建 | 大量刷题、多题型支持、进度追踪 | 2000 万+ |
| 企业培训部门 | 新员工考核、安全生产培训、合规考试 | 自建题库、批量导入、考试模式 | 800 万企业 |
| 自由学习者 | 读书笔记、知识点记忆、兴趣学习 | 自定义问答、每日打卡、统计分析 | 5000 万+ |

### 2.2 客户核心需求

1. **题库自由**：不被平台题库绑架，能自己创建专属题库
2. **多题型支持**：不仅限于选择题，填空、简答同样是刚需
3. **批量导入**：已有题目能快速导入，无需逐题手打
4. **碎片化练习**：通勤、排队等场景随时刷几题
5. **错题管理**：自动收集错题，针对性强化薄弱知识点
6. **云同步免费**：跨设备同步学习进度，不额外付费

### 2.3 竞争对手分析

| 竞品 | 优势 | 劣势 | 智练的应对 |
|------|------|------|-----------|
| **粉笔** | 公考题库全面、品牌知名度高 | 题库封闭不可自建，内容由平台控制 | 开放题库 + 自建导入 |
| **猿题库** | K12 覆盖广、AI 推荐 | 用户面窄（仅 K12），不支持自建 | 全年龄段 + DOCX 解析 |
| **考试宝** | 功能覆盖面广 | 界面传统、题型仅支持选择判断 | 5 种题型 + 现代 UI |
| **Anki** | 间隔记忆算法成熟、开源 | 中文生态差、仅卡片式、无云同步 | 中文优先 + 免费云同步 |
| **刷题神器** | 运营成熟、用户量大 | 广告多、付费墙高 | 免费增值，体验优先 |

### 2.4 差异化优势

| 维度 | 智练 | 行业现状 |
|------|------|---------|
| **题型覆盖** | 单选 / 多选 / 判断 / 填空 / 简答 | 多数仅支持选择判断 |
| **题库来源** | 手动录入 + JSON/CSV/DOCX 导入 | 以平台提供为主 |
| **DOCX 解析** | 自动识别题干、选项、答案、解析 | 竞品均无此能力 |
| **云同步** | Supabase 免费云同步 | 多数需付费 |
| **分发方式** | 独立 APK + 应用商店 | 仅应用商店 |
| **技术栈** | Expo/RN 跨平台，一套代码双端 | 多为原生或 Web 封装 |

**市场核心痛点**：「题库由平台提供，用户无法灵活自建」×「支持自建的产品不支持多题型」×「云同步普遍需要付费」→ 智练一举解决三个痛点。

### 3.2 核心功能

| 功能模块 | 说明 |
|---------|------|
| **用户认证** | 邮箱注册/登录，SecureStore 加密存储 Token，会话自动恢复 |
| **题库管理** | 手动录题（5 种题型动态表单）、JSON/CSV/DOCX 三种导入方式、搜索筛选分页 |
| **答题系统** | 5 种题型专属交互、自由练习（即时判分+解析）、试卷模式（统一提交打分）、答题计时器 |
| **每日打卡** | 完成 20 题自动打卡、日历热力图、连续天数统计 |
| **错题本** | 答题错误自动收录、错误次数累计记录、错题重练 |
| **题目收藏** | 答题中一键星标、独立收藏列表、收藏题专项练习 |
| **学习统计** | 总答题数、正确率、各题型作答进度、薄弱知识点排行 |
| **数据导出** | 一键导出全部个人数据（题库、错题、收藏、打卡）为 JSON |

### 3.3 产品亮点（与同类产品的关键差异）

#### 🧠 DOCX 智能解析引擎
上传 Word 试卷自动识别题目结构：自动提取题干、匹配选项字母（A/B/C/D）、检测答案标记（如"答案：A"）、抓取解析段落、智能过滤试卷标题和章节编号。**竞品无一具备此能力。**

#### 🎛 题型自适应表单
录题时切换题型，表单即时变化：单选→选项+单选按钮，多选→选项+勾选框，判断→对错大按钮，填空/简答→文本输入。一个表单适配全部题型，操作连贯不中断。

#### 🎯 智能判分系统
- 简答题：**关键词匹配算法**，参考答案拆为关键词，命中半数以上视为正确
- 填空题：精确字符串比对（忽略大小写和首尾空格）
- 多选/填空/简答：需手动**「确认答案」**后才判分，防止误触

#### ⚡ 离线优先架构
本地 SQLite 缓存全量数据（题目、标签、答题记录），断网环境下完整可用；网络恢复后自动与 Supabase 云端同步。

#### 📱 独立 APK 分发
通过 Expo EAS Build 云端构建独立 APK，用户可直接下载安装，**无需应用商店**。完美支持华为等没有 Google Play 的国产手机。

### 3.5 数据库设计

| 表名 | 用途 | 关键字段 |
|------|------|---------|
| `questions` | 题目主表 | type, stem, options(JSONB), answer(JSONB), analysis, difficulty |
| `tags` | 题库标签 | name, color |
| `question_tags` | 题目-标签多对多 | question_id → questions, tag_id → tags (CASCADE) |
| `papers` | 试卷 | title, description, question_count |
| `paper_questions` | 试卷-题目关联 | paper_id → papers, question_id → questions (CASCADE) |
| `practice_records` | 答题记录 | question_id, user_answer, is_correct, time_spent |
| `wrong_questions` | 错题本 | question_id, wrong_count, last_wrong_at |
| `favorites` | 收藏 | question_id |
| `daily_checkins` | 每日打卡 | date, question_count |
| `user_notes` | 用户笔记 | question_id, content |

所有表均启用 **Row Level Security**，`user_id = auth.uid()` 确保用户数据完全隔离。

## 四、商业模式

### 4.1 收入来源

| 收入来源 | 说明 | 预估占比 |
|----------|------|---------|
| **免费增值 (Freemium)** | 基础功能永久免费：手动录题、基础答题、JSON/CSV/DOCX 导入（50 题以内）、每日打卡、错题记录、收藏、基础统计 | 0%（引流） |
| **会员订阅** | 月/年订阅制，解锁：无限题库导入、高级统计分析、数据导出、深色模式、去广告、优先体验新功能 | 60% |
| **题库市场** | 优质题库创作者可定价售卖（如考研政治 3000 题 ¥9.9），平台抽取 20% 技术服务费。形成 UGC 内容生态 | 25% |
| **企业定制** | 面向企业培训场景提供私有化部署、SSO 单点登录集成、定制题型开发、专属品牌皮肤，按年付费 | 15% |

### 4.2 定价策略

| 方案 | 价格 | 目标用户 |
|------|------|---------|
| 免费版 | ¥0 | 轻度自用学习者 |
| 月度会员 | ¥12 ~ ¥18 | 备考冲刺期用户 |
| 年度会员 | ¥98 ~ ¥128 | 长期重度用户（日均 ¥0.27 ~ ¥0.35） |

**定价逻辑**：以一杯奶茶/月的亲民价格覆盖从轻度到重度用户的完整付费梯度。年度订阅日均不到 4 毛钱，远低于同类产品（粉笔会员 ¥30+/月）。

### 4.3 核心竞争力壁垒

| 壁垒 | 说明 | 可持续性 |
|------|------|---------|
| **DOCX 智能解析** | 业界独有的 Word 文档自动识别题目引擎，积累了特殊格式处理能力 | 技术壁垒，难以短期复制 |
| **数据网络效应** | 用户自建题库越多，平台内容越丰富；题库市场形成双边网络 | 随用户规模增长而增强 |
| **全题型覆盖** | 单选/多选/判断/填空/简答五种题型完整支持，切换无缝 | 产品完整性壁垒 |
| **离线优先** | SQLite + Supabase 双写架构，断网也能用 | 架构壁垒 |
| **开源透明** | 代码完全开源，用户可审计、可自部署、可贡献 | 信任壁垒 |
