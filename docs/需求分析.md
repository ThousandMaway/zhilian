## 三、用户故事

1. 作为备考学生，我希望能够导入自己的题库，以便针对性地练习
2. 作为用户，我希望答错的题自动记录，以便后续复习
3. 作为用户，我希望看到每日打卡记录，以保持学习习惯
4. 作为用户，我希望随机练习时可以指定题型和来源，以提高练习效率
5. 作为用户，我希望题库练习时能从头到尾顺序做，以模拟考试环境
