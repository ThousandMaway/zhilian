# 智练 App — 演示视频脚本

> 建议总时长：3-5 分钟 | 录制工具：手机系统录屏

---

## 前置准备

- [ ] 注册一个测试账号
- [ ] 导入 `test-data/` 中的示例题库（前端基础.json、公考常识.json）
- [ ] 手动录入 2-3 道不同题型的题目
- [ ] 提前答过一些题（有打卡记录和错题）
- [ ] 开启勿扰模式，关闭通知

---

## 场景一：注册登录（~15 秒）

| 画面 | 操作 | 旁白 |
|------|------|------|
| App 启动 → 登录页 | 点击「注册」 | "打开智练，用邮箱注册即可" |
| 注册页 | 输入邮箱密码 → 注册 | "注册后自动登录，Token 加密存储" |
| 首页 | 展示首页 | "登录后进入首页" |

---

## 场景二：DOCX 智能导入（~40 秒）⭐亮点

| 画面 | 操作 | 旁白 |
|------|------|------|
| 底部 →「题库」Tab | 点题库 | "进入题库管理" |
| 题库页 | 点「导入题库」 | "支持 JSON、CSV、DOCX 三种导入" |
| 导入页 → DOCX | 选择 Word 文档 | "重点是 DOCX 智能解析" |
| 解析预览 | 展示自动识别的题目 | "题干、选项、答案、解析全部自动提取" |
| 确认导入 | 点导入 → 回题库 | "一键导入，自动创建标签" |

---

## 场景三：手动录题 — 自适应表单（~25 秒）⭐亮点

| 画面 | 操作 | 旁白 |
|------|------|------|
| 题库页 | 点「手动录题」 | "也可以手动录入" |
| 默认单选 | 填题干 | "默认单选题" |
| 切换题型 | 点「多选题」→「判断题」→「填空题」 | "切换题型，表单即时变化——一个表单适配全部" |
| 保存 | 填完 → 创建题目 | "选标签、设难度，保存" |

---

## 场景四：答题系统（~50 秒）⭐核心

| 画面 | 操作 | 旁白 |
|------|------|------|
| 底部 →「答题」Tab | 点答题 | "进入练习" |
| 模式选择 | 展示 5 种模式 | "随机、题库、试卷、错题、收藏" |
| 选「题库练习」 | 点「前端基础」 | "选一个题库" |
| 答单选题 | 点选项 → 即时判分 | "即时显示对错和解析" |
| 答多选题 | 勾选 →「确认答案」 | "多选需确认，防止误触" |
| 答判断题 | 点正确 | "判断题一键作答" |
| 答填空题 | 输入 → 确认 | "填空题精确比对" |
| 答简答题 | 输入关键词 → 确认 | "简答题关键词匹配算法自动判分" |
| 收藏 | 点⭐ | "做题时可一键收藏" |
| 提交 | 点「提交」→ 结果页 | "查看成绩" |
