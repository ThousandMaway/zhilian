## 二、数据库设计

### 2.1 核心表

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| questions | 题目 | id, user_id, type, stem, options(JSONB), answer(JSONB), analysis, difficulty |
| tags | 标签 | id, user_id, name, color |
| question_tags | 题目标签关联 | question_id, tag_id (多对多) |
| papers | 试卷 | id, user_id, title, description |
| paper_questions | 试卷题目 | paper_id, question_id, sort_order |
| practice_records | 答题记录 | id, user_id, question_id, user_answer, is_correct, time_spent |
| wrong_questions | 错题 | id, user_id, question_id, wrong_count |
| favorites | 收藏 | id, user_id, question_id |
| daily_checkins | 打卡 | id, user_id, date, question_count |
| user_notes | 笔记 | id, user_id, question_id, content |

### 2.2 安全策略

所有表启用 Row Level Security（RLS），策略：`auth.uid() = user_id`

## 四、状态管理

### 4.1 Zustand Stores

| Store | 状态 | 用途 |
|-------|------|------|
| useAuthStore | user, session, isAuthenticated | 认证状态和生命周期 |
| usePracticeStore | mode, questions, currentIndex, answers | 答题会话状态 |

### 4.2 TanStack Query

- `useQuestions(filters)` — 题目列表（分页、搜索、筛选）
- `useCreateQuestion/useUpdateQuestion/useDeleteQuestion` — 题目 CRUD
- `useBulkImportQuestions` — 批量导入 + 自动打标签
- `usePracticeRecords/useWrongQuestions` — 答题记录和错题
- `useDailyCheckins/useUpsertCheckin` — 打卡
- `useFavorites/useToggleFavorite` — 收藏
- `useTags/useUpdateTag/useDeleteTag` — 标签管理

## 五、关键算法

### 5.1 DOCX 智能解析

1. `mammoth.extractRawText()` 提取纯文本
2. 按题目编号正则分割为题目块
3. 每题内部识别：选项行(A-D)、答案标记(答案/参考答案)、解析标记(解析/分析)
4. 推断题型（多选/判断/填空/简答）
5. 过滤章节标题和试卷标题

### 5.2 简答题判分

1. 将参考答案按逗号/顿号/空格分割为关键词
2. 用户答案转为小写
3. 统计匹配的关键词数量
4. 匹配 ≥ 50% 即判为正确

### 5.3 连续打卡计算

1. 获取 365 天内所有打卡日期
2. 从今天开始向前遍历
3. 遇到缺失日期即中断
4. 返回连续天数
